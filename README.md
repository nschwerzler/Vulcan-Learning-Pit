# Vulcan-Learning-Pit

A learning and experimentation repository for .NET development. This repository serves as a practice ground for exploring .NET technologies, testing new concepts, and developing coding skills.

## Purpose

This repository is designed to:
- Experiment with .NET features and capabilities
- Practice coding patterns and best practices
- Test new libraries and frameworks
- Serve as a reference for future projects

## Getting Started

### Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download) (latest version recommended)
- Your preferred IDE:
  - [Visual Studio](https://visualstudio.microsoft.com/)
  - [Visual Studio Code](https://code.visualstudio.com/)
  - [JetBrains Rider](https://www.jetbrains.com/rider/)

### Building and Running

Clone the repository:
```bash
git clone https://github.com/nschwerzler/Vulcan-Learning-Pit.git
cd Vulcan-Learning-Pit
```

Build projects:
```bash
dotnet build
```

Run tests:
```bash
dotnet test
```
